
Smart Pill Reminder and Automatic Medicine Dispensing System
About This Project

An IoT-enabled smart medicine reminder and automatic pill dispensing system designed to help users manage their weekly medication schedule. The system automatically reminds users at the scheduled time, rotates to the correct medicine compartment, opens the required pill compartment, and records user acknowledgement through a custom mobile application and IoT platform.

Tech

Arduino Nano, ESP32, Arduino IDE, Servo Motors, Mobile Application, IoT Server, Embedded C++, Bluetooth/Wireless Communication, AI Assisted Medicine Information

Abstract

The Smart Pill Reminder and Automatic Medicine Dispensing System is an IoT-enabled healthcare device developed to simplify medication management and improve adherence to prescribed medicine schedules. The system consists of a circular medicine container containing seven daily compartments, each divided into multiple time-based medication slots. Users configure their weekly medicine schedule using a custom mobile application, where medicines, dispensing times, and corresponding daily slots are assigned.

At the scheduled time, the system automatically rotates the dispensing mechanism to the correct compartment using a precision servo motor. A second synchronized servo motor opens the corresponding compartment lid, allowing the user to access only the required medication while keeping the remaining medicines safely enclosed beneath a transparent protective cover.

Visual and audible alerts notify the user when medication is ready. After collecting the medicine, the user confirms the action by pressing an acknowledgement button, which immediately stops the reminder and records successful medicine collection. A custom ESP32-based communication module synchronizes the hardware with a custom IoT server and mobile application, enabling centralized schedule management and future intelligent healthcare services. The complete system is designed as a compact PCB-based prototype that integrates embedded electronics, IoT communication, mobile software, and automated mechanical dispensing into a practical healthcare solution.

Project Description

Managing medicines on time is one of the biggest challenges for elderly individuals, patients with chronic illnesses, and users taking multiple medications every day. Traditional pill organizers depend entirely on the user's memory, increasing the possibility of missed or incorrect doses.

To address this problem, this project introduces an IoT-enabled Smart Pill Reminder and Automatic Medicine Dispensing System that automates medicine reminders while simplifying medicine retrieval.

The system consists of a circular medicine storage container divided into seven daily compartments representing the days of the week. Each day's compartment contains multiple medicine slots that correspond to scheduled medication times such as morning, afternoon, evening, and night. The medicine compartments are enclosed beneath a transparent protective cover that protects medicines from dust, moisture, and environmental exposure while allowing users to visually monitor remaining pills.

Users configure their weekly medication schedule using a custom mobile application. For every medicine reminder, the user selects the day, dispensing time, and corresponding compartment. This information is synchronized with a custom IoT server and transmitted to the embedded hardware through wireless communication.

When a scheduled reminder time is reached, the dispensing mechanism automatically activates. A precision servo motor rotates the central dispensing assembly until it aligns with the appropriate medicine compartment. Once correctly positioned, a second synchronized servo motor opens the corresponding compartment lid, allowing access only to the scheduled medicine while keeping every other compartment securely closed.

Simultaneously, LEDs and a buzzer notify the user that medication is ready for collection. After removing the medicine, the user presses a dedicated acknowledgement button. This confirmation immediately stops the alert and records that the scheduled medicine has been collected successfully.

The complete system is built around an Arduino Nano for real-time motor control and hardware coordination, while an ESP32 provides wireless communication between the embedded device, custom mobile application, and IoT server. The modular system architecture also provides a foundation for future intelligent healthcare features, including AI-assisted medicine information and personalized medication support.

Designed as a compact PCB-based prototype, the project combines embedded electronics, mechanical automation, mobile application development, and IoT technologies into a complete smart healthcare product.

Conclusion

The Smart Pill Reminder and Automatic Medicine Dispensing System demonstrates how embedded systems, IoT communication, and mechanical automation can be combined to simplify daily medication management. By automatically identifying the scheduled medicine compartment, rotating the dispensing mechanism, opening only the required compartment, and notifying the user through visual and audible alerts, the system minimizes missed doses while improving convenience and medication safety.

The integration of a custom mobile application and IoT server enables centralized schedule management and flexible medication planning, while the acknowledgement mechanism confirms successful medicine collection. Built as a compact PCB-based prototype, the system establishes a scalable platform for future intelligent healthcare features and provides a practical foundation for next-generation automated medication management products.
